# Turan Oto Yedek Parça — Next.js

## Yerelde çalıştırma

Node.js 20.9 veya üzeri gereklidir.

```bash
npm install
npm run dev
```

Tarayıcı:
http://localhost:3000

## GitHub'a yükleme

ZIP'i çıkartın. GitHub deposunda **Add file → Upload files** seçin.
ZIP dosyasının kendisini değil, çıkartılan klasörün içindeki tüm dosya ve klasörleri yükleyin.

## Vercel

Vercel → Add New → Project → GitHub deposunu seç → Deploy.

Bu sürüm:
- Vercel'e doğrudan deploy olur
- Ana sayfa, ürünler, filtreler, ürün detay ve sepet çalışır
- Ürün fotoğrafları içerir
- Kullanıcı/admin/şasi ekranları hazırlanmıştır

Sonraki backend aşaması:
- PostgreSQL
- Auth.js
- Kullanıcı/adres/sipariş tabloları
- iyzico veya PayTR
- Gerçek admin CRUD
